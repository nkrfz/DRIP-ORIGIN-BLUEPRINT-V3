# DRIP / ORIGIN V3 — Six Interactive Atmospheres

Это полноценная версия фронтенда интернет-магазина кофе для HoReCa. Основа — **единая полноэкранная 3D-история без карточек с текстом**. Шесть форм собираются из десятков тысяч бирюзовых точек, а типографика и положение модели чередуются по мере прокрутки.

## Как открыть сайт на Windows за два клика

1. Распакуйте архив **DRIP-ORIGIN-BLUEPRINT-V3.zip**.
2. Откройте папку `DRIP-ORIGIN-BLUEPRINT-V3` и дважды нажмите **`OPEN-PREVIEW.html`**.

Это полностью автономный HTML-файл: для него не нужен Node.js, npm, сервер или интернет. Просмотр работает в Microsoft Edge и Chrome. Исходники Next.js лежат в тех же папках.

Если хотите запустить именно Next.js, установите Node.js LTS, затем в папке проекта запустите `START-WINDOWS.bat` либо из PowerShell выполните:

```powershell
npm install
npm run dev
```

Откройте `http://localhost:3000` в браузере. Это **только фронтенд**: каталог, оформление заказа и корзина демонстрационные, оплаты и сервера заказов нет.

## Управление

- **Колесо мыши / тачпад** — переход по шести сценам.
- **Вертикальный ползунок справа** — точная перемотка между сценами; управляется клавиатурными стрелками.
- **Нижняя навигация 01–06** — прямой переход к сцене.
- **Курсор на фоне** — маленькие элементы отталкиваются и возвращаются на место, полупрозрачный дым рассеивается вслед за курсором.
- **Удержание левой кнопки и движение мыши** — свободное вращение основной точечной модели.
- **Перемещение курсора на сцене чашки** — круговые волны на кофейной поверхности.
- **Коллекция / О нас / Для бизнеса / Корзина** — работают как полноценные страницы в Next.js и как автономные панели в HTML-превью.

### Почему модель дольше видна

Теперь сайт растянут на `760svh`. Каждая сцена удерживает форму примерно **79% своей дистанции прокрутки**, и только оставшиеся 21% отведены на морфинг в следующую форму. Пользователь может изучать и крутить модель сколько угодно, просто не прокручивая дальше. Переходы по-прежнему плавные.

## Где менять эффекты

- `components/ParticleShapes.ts` — функции `bean`, `cherry`, `drip`, `cup`, `tree`, `hotelKey`: математические поверхности 3D-объектов; `morphProgress` задаёт время удержания.
- `components/ParticleScene.tsx` — R3F и шейдер GLSL, шесть 3D-наборов координат, интерактивное вращение, попеременное позиционирование.
- `components/ImmersiveHome.tsx` — экранная история, шесть текстов, CTA, GSAP и ползунок.
- `public/effects/atmosphere.js` — более тысячи фоново нарисованных зёрен/листьев на широких мониторах, интерактивная физика отталкивания, 2D/WebGL-волны и новый слой полупрозрачного дыма.
- `public/effects/fallback-cloud.js` — адаптивная 2D-версия всех шести форм, если WebGL или анимация недоступны.
- `OPEN-PREVIEW.html` — автономная HTML-версия: код анимаций/сцен встроен внутрь документа, чтобы он открывался двойным кликом.
- `data/products.json` — 80 демонстрационных товаров.

**Качество:** до 68 000 основных GPU-частиц на десктопе; 26 000 на средних экранах; ECO — 14 000; 2D-резервный режим — до 10 500 точек. Фоновые зерна и листья рисуются отдельным canvas с ограничением частоты кадров; дым рисуется в пониженном разрешении и не закрывает главную модель. На мобильных используется меньше фоновых элементов. `prefers-reduced-motion` и резервные изображения предусмотрены.

Модель `.glb` для запуска не требуется. Чтобы заменить геометрию на свою, потребуется сэмплирование поверхности GLB через `MeshSurfaceSampler`, а не просто копирование файла в `public/models`.
